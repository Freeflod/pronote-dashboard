# Étiquettes

| Étiquette | Sens |
|---|---|
| `bug` | le plugin fait autre chose que ce qui est attendu |
| `enhancement` | une amélioration ou une fonctionnalité nouvelle |
| `dette` | un compromis accepté, à solder plus tard (toujours avec l'ADR ou la PR qui l'a accepté) |
| `documentation` | documentation seule |
| `question` | besoin d'information, pas de changement attendu |
| `good first issue` | petit périmètre, bien décrit, adapté à une première contribution |

Triage : une issue reçoit une étiquette de type (`bug`, `enhancement`, `dette`, `documentation` ou `question`). Un bug sans étapes de reproduction reste en attente d'informations. Aucune issue ne reste avec une donnée réelle : elle se modifie ou se supprime dès qu'on la repère, et le signalement se fait au mainteneur.
